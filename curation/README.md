# Source review for the rubric-aligned replacement

The existing Qwen experiment remains historical evidence, not evidence of a LLaMA run.
The replacement corpus must trace every operational statement to an authoritative source.

Source PDFs in `data_sources/` were downloaded directly from Kenya Law. Their embedded attribution and licensing notices are preserved. Statutory text is distinguished from project-authored operational paraphrases. Document versions are pinned; this does not establish that no later amendment or interpretation exists.

A human reviewer must check each question, answer, cited clause and operational interpretation, including current applicability, before the replacement corpus is described as manually verified. No clinician, facility owner or instructor sign-off is inferred from automated checks. Review does not authorize diagnostic advice.
